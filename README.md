# 🚗 Современный одностраничный сайт-визитка для автоклуба Subaru. 

## ✨ Возможности

- 🎨 **Современный минималистичный дизайн** — тёмная тема с фирменными цветами Subaru
- 📱 **Полная адаптивность** — отлично выглядит на мобильных, планшетах и десктопах
- ⚡ **Высокая производительность** — чистый HTML/CSS/JS без тяжёлых фреймворков
- 🔍 **SEO-оптимизация** — мета-теги, микроразметка Schema.org, Open Graph
- 🎬 **Плавные анимации** — появление блоков при скролле, hover-эффекты
- 🗺️ **Локальное SEO** — гео-теги для Тюмени
- 🔗 **Интеграция с ВК** — кнопки для двух групп сообщества

## 🛠 Технологии

| Технология | Назначение |
|------------|------------|
| HTML5 | Семантическая разметка |
| CSS3 (Custom Properties) | Стили и анимации |
| Vanilla JavaScript | Интерактивность |
| [Inter](https://rsms.me/inter/) | Шрифт через Fontsource CDN |
| Schema.org | Микроразметка для поисковиков |
| Open Graph | Превью при шаринге |
